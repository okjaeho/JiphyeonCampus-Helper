# 집현캠퍼스 헬퍼

세종대학교 집현캠퍼스에서 내가 수강하는 강좌의 온라인 강의, 미완료 활동, 공지와 자료를 한곳에서 확인하는 Chrome 확장 프로그램입니다. 편리한 강의 시청을 위해 연속 재생, 드래그로 정렬하는 플레이리스트, 볼륨 유지와 크기 조절 미니플레이어를 지원합니다.

## 설치

1. 압축을 **계속 보관할 위치**에 풀어주세요.
2. Chrome 주소창에 `chrome://extensions`를 입력하세요.
3. 오른쪽 위 **개발자 모드**를 켜세요.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 압축을 푼 곳의 **extension 폴더**를 선택하세요.
5. [집현캠퍼스](https://ecampus.sejong.ac.kr/login.php)에 본인 계정으로 로그인하세요.
6. 학교 페이지를 새로고침하고 **강의 모아보기**를 누르세요. Chrome의 확장 아이콘으로도 열 수 있습니다.

업데이트했을 때는 확장 관리 화면에서 헬퍼의 새로고침 버튼을 누르고 학교 페이지도 새로고침하세요.

## 사용

- 영상을 선택해 연속 재생합니다. 재생목록은 드래그로 정렬하고, 아이콘으로 재생/일시정지·중지·확대합니다. 볼륨은 기본 0%이며 저장됩니다.
- 미완료 활동·공지·자료실은 별도 목록에서 확인합니다. 공지는 최근 7일만 먼저 표시하며 **더 불러오기**로 이전 글을 봅니다.
- 패널 왼쪽과 영상 아래 손잡이로 크기를 조절합니다. 확인 창이나 재생 중단은 연한 빨강 배경으로 표시됩니다. 출석 반영은 학교 출석부에서 확인하세요.

## 파일 보관

설치 후 **압축파일과 README는 삭제해도 됩니다. extension 폴더는 삭제하거나 옮기지 마세요.** Chrome이 그 폴더를 계속 사용합니다. 옮겼다면 새 위치에서 다시 불러오세요.

배포 파일에는 이름·학번·비밀번호·로그인 쿠키·수강 목록이 포함되지 않습니다. 각자 로그인한 계정을 사용하며, 설정은 본인의 Chrome에만 저장됩니다.

## 작동 방식

로그인된 브라우저에서 집현캠퍼스의 강좌 페이지를 읽어 목록을 정리하고, 학교에서 제공하는 원래 영상 플레이어를 헬퍼 안에 열어 한 강의씩 1배속으로 재생합니다. 영상이 끝나면 학교 플레이어의 종료 절차를 거쳐 완료 반영을 확인한 뒤 다음 강의로 넘어갑니다. 출석·진도를 임의로 변경하거나 학습 확인 질문에 자동으로 응답하지 않습니다.

로그인 정보와 쿠키를 별도로 수집·저장하거나 외부 서버로 보내지 않습니다. 볼륨, 정렬 순서, 화면 크기 등의 설정은 사용자의 Chrome에만 저장됩니다.

## 이용 안내

세종대학교에서 제공하거나 승인한 공식 프로그램이 아닌 개인 제작 도구입니다. 오류 없는 동작이나 출석 반영, 제재 없는 사용을 보장하지 않으므로 학교의 이용 정책과 출석 결과를 직접 확인해주세요. **사용으로 발생하는 출석 누락, 계정 제재 및 기타 불이익에 대해 제작자는 책임을 지지 않습니다.**
